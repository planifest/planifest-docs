# Domain Glossary - 0000001-doc-nav

| Term | Definition |
|------|-----------|
| **Page manifest** | `docs.manifest.json` — the ordered array of doc page entries (`file`, `title`) that is the single source of truth for navigation generation |
| **Doc page** | A generated HTML file in `src/web-app/docs/` produced from a planifest-docs markdown source |
| **Top nav** | The `<nav class="glass-nav">` element at the top of every doc page containing site-wide and doc page links |
| **Doc nav links** | The subset of top nav links that point to doc pages, generated from the manifest |
| **Prev/next nav** | The `<nav class="doc-pagination">` block injected at the bottom of each doc page inside `<main>` |
| **CTA link** | The "Read the Docs" call-to-action anchor on the homepage (`index.html`) |
| **build artefact** | Any file in `src/web-app/docs/` — generated by `build-docs.js`, not authored by hand |
| **Template placeholder** | A `{{TOKEN}}` string in the HTML template replaced by `build-docs.js` at build time |
| **Manifest order** | The sequence of pages as listed in `docs.manifest.json` — defines both nav display order and prev/next relationships |
