## Findings

| ID | Severity | Category | Component | Description | Recommendation | Status |
|----|----------|----------|-----------|-------------|----------------|--------|
| S-001 | medium | injection | src/web-app/src/main.ts | `mermaid.initialize({ securityLevel: 'loose' })` disables Mermaid's built-in HTML sanitization in diagram labels. Any Mermaid block in a doc file that includes raw HTML will render it — this is intentional for `<br>` support but also allows `<script>` tags in diagram labels if a doc author includes them. | Changed to `securityLevel: 'antiscript'` — allows `<br>` and basic formatting, blocks `<script>`. | mitigated |
| S-002 | low | injection | src/web-app/src/main.ts:117 | `navLinks.innerHTML += extraLinksHTML` concatenated strings from `sitemap-data.json` (item.file, item.title) without HTML-escaping. | S-003 | informational | config | src/web-app/src/main.ts:31 | `document.querySelector(window.location.hash)` — if the URL fragment contains an invalid CSS selector (e.g. `#foo[bar`), `querySelector` throws a `SyntaxError`. | S-004 | informational | dependency | src/web-app | `marked` parses untrusted markdown into HTML in `build-docs.js`. ## Recommendations

Ordered by priority:

1. **(S-001)** Change `mermaid.initialize({ securityLevel: 'loose' })` to `'antiscript'` or `'strict'` to re-enable Mermaid's HTML sanitization. `antiscript` allows `<br>` and basic formatting while blocking `<script>`.
2. **(S-002)** HTML-escape `item.title` before concatenation into `navLinks.innerHTML`.
3. **(S-003)** Wrap `document.querySelector(window.location.hash)` in a try/catch to prevent unhandled SyntaxError on malformed fragments.
