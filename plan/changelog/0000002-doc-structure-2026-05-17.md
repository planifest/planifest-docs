# Changelog: 0000002-doc-structure — 17 May 2026

## Summary

Restructured framework and website documentation into a three-file architecture with a two-tier depth model.

## Changes

### planifest-framework/

- **getting-started.md** — Trimmed to steps 1–5 only (prerequisites, add framework, create structure, run setup, open tool). All operational reference content removed.
- **project-operations.md** — Created. Brief high-level ops reference covering Git Guardrails, Orchestrator Sentinel, Strict Mode, Customising, Updating, What to Commit, and Retrofit. Each section ≤15 lines with `→` pointer to pipeline-reference.md.
- **pipeline-reference.md** — Expanded with six new sections: Git Guardrails (3-tier table, hook locations, violation messages), Orchestrator Sentinel (full lifecycle, 3 hooks, manual recovery), Strict Orchestrator Mode (ack file lifecycle, setup commands), Retrofit an Existing Project (full discovery protocol), Updating the Framework (command matrix, migrations), What to Commit (full table with Optional explanation).

- **03-pipeline.md** — `plan/archive/` → `plan/_archive/` corrected.
- **08-agent-skills-reference.md** — `plan/archive/` → `plan/_archive/` corrected.

### src/web-app/
