## What Was Built

Doc site navigation was hardcoded and broken — the homepage CTA was a 404, only one doc page appeared in the top nav, and no prev/next navigation existed between pages. This feature replaced all of that with manifest-driven generation at build time.

- `src/web-app/docs.manifest.json` — ordered page manifest (10 doc pages); single source of truth for page titles and sequence
- `src/web-app/scripts/build-docs.js` — extended to inject top nav links into all doc pages, inject prev/next nav at page bottom, and fix the broken homepage CTA link
- `docs/` — component registry, dependency graph, system context

## Decisions

- **ADR-001:** JSON manifest at `docs.manifest.json` is the single source of truth for page order and titles — chosen over filesystem discovery (non-deterministic) and frontmatter (parsing overhead)
- **ADR-002:** Nav HTML injected via template placeholder in `build-docs.js` — no runtime JS, consistent with existing static build pattern
